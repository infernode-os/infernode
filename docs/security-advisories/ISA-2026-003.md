## Summary

Inferno lets a process name its environment device as `#e` even after
`NODEVS`. Tool workers inherited the environment group of the process
that launched them, so a worker whose `/env` had been narrowed could
read the launcher's variables by spelling the path `#e`.

## Impact

An agent's tool could read every environment variable of the session
that started it, whatever its `/env` view said.

## Fix

Every tool worker starts with `NEWENV` and carries only
`VELTRO_SESSION`.

## Workarounds

None. Update to 0.4.1 or later.

Found internally (INFR-480).
