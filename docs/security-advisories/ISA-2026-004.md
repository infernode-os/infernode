Title: A malformed 9P directory entry could be read past its buffer
Severity: medium

Changelog: 0.4.1

## Summary

`statcheck` advanced through a 9P directory read by string lengths the
server sent, without checking them against the bytes returned. A
directory entry with a long length read past the end of its buffer.

## Impact

A 9P server the emulator mounts, local or remote, could make the
emulator read out of bounds and fault, ending the emulator and every
program in it.

## Fix

Each entry is checked against the remaining span before any of its
fields is decoded.

## Workarounds

Mount only 9P servers you trust. Update to 0.4.1 or later.

Found internally (INFR-479).
