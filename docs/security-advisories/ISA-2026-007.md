Title: An agent's native tool call could skip the operator's approval

## Summary

The agent harness (`veltrosrv`) decides which tool calls need the
operator's approval by reading their arguments. A model's native tool
call sends its arguments as JSON (`{"path": ..., "content": ...}`), and
the approval check read that text as if it were the tool's positional
form, so it found no protected path and no `rm`: a `write` or `exec`
that needed approval went to the tool unasked. The golden test for the
case had recorded the bypass as the expected result.

## Impact

A model, or text that steered it, could make a gated write or command
run within the agent's grants without the operator being asked.

## Fix

The check judges the form the tool is actually called with. The golden
test records the denial.

## Workarounds

None. Update to 0.6.0 or later. (ISA-2026-024 is a later fault in the
same gate.)

Found internally.
