Id: ISA-2026-009
Title: A password typed into the browser was readable through its files
Severity: medium
CWE: CWE-522 CWE-200
Affected: < 0.8.1
Patched: 0.8.1
Commits: c5bdf6eaa
Changelog: 0.8.1
GHSA:
CVE:

## Summary

Charon serves each browser window as files. The `forms` file and a
password input's `dom/N/attrs` showed the field's value as typed or as
filled from factotum.

## Impact

Anything that could read a browser window's files, an agent given the
window among them, could read passwords entered in it.

## Fix

Both files show `********` when the field holds anything. The page, its
scripts and the submitted form still have the value.

## Workarounds

Do not give an agent the files of a window in which you type passwords.
Update to 0.8.1 or later.

Found internally (INFR-544).
