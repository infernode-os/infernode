## Summary

The agent confinement stack let text a model chose decide what only the
human or the harness should:

- the approval gate read a tool call's arguments one way and the tool
  another, so a promote spelt `Promote` applied a task's staged changes
  unasked; the request shown to the user was the first 160 characters
  as written, so the gated part could lie past them or be overdrawn by
  a carriage return; `sms` and `dial` were not asked about;
- cowfs's own records (`.cowmeta`, `.cowbase`, `.whiteout`) could be
  written through the overlay, and lucibridge took the folder a promote
  writes to from `.cowmeta`: a task with `write` and one granted folder
  had the user's ordinary Allow write its files into any directory the
  user could write;
- a subagent's name space kept its parent's `/tool/<tool>` files, so a
  child given `read` and no paths read its parent's files and results
  through them, and could be granted `/mnt/llm`, where every session's
  conversation is.

## Impact

A model, or remote content that steered it, could write outside its
granted folders, send text messages or place calls without the user
being asked, and reach authority its delegation did not give it.

## Fix

The gate judges the parsed call that will run and shows it whole; task,
sms and dial describe their own effect and are asked about. cowfs keeps
its records out of the tree it serves and lucibridge applies changes
only to the folder it noted as granted. A subagent's `/tool` is a
read-only description with no tool server; `/mnt/llm` and
`/mnt/veltro` are refused as grants. `git` left the default delegation
budget (ISA-2026-025).

## Workarounds

None. Update to 0.11.0 or later. On an earlier release, review what a
task staged before allowing a promote.

Found by the project's security review.
