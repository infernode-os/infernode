edit - Edit file contents (find/replace)

Usage:
  edit <path> <old> <new>       Replace first occurrence
  edit <path> <old> <new> all   Replace all occurrences

Arguments:
  path - File to edit
  old  - Text to find (quote if contains spaces)
  new  - Replacement text
  all  - Optional: replace all

Called with arguments by name (path, old, new), old and new are the text
itself: line breaks as line breaks, nothing unescaped.  Only the one-line
form above takes \n for a newline and \t for a tab.

Fails if old text not found. Without 'all', fails if multiple matches.
