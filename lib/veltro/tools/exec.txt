exec - Run command in Inferno shell (rc-style, not POSIX)

  exec <command>

Only the shell and the commands this task was granted are here: a command
is a capability, granted by name. Without a grant, only the shell's own
builtins run (echo, cd, load, ...); ls, cat and the rest do not exist.
For files use read/write/edit/list/find/grep; for Limbo, the limbo tool
("limbo compile <file.b>" checks a file compiles).

Shell differences from bash:
  - Single quotes (double quotes auto-converted)
  - Use ; not && for chaining
  - for i in $list { cmd }   (not do/done)
  - $var not ${var}

Examples (with the commands granted):
  exec ls /appl
  exec 'for f in *.b { echo $f }'

Timeout: 30s default; -t <seconds> before the command (or timeout, by
name) sets another, at most 120.  A long output is shown as its start and
its end, with how much was left out between.
