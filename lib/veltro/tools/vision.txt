vision - What is in a picture

Usage:
  vision [-c class,...] [-t thresh] imagepath

Returns one line for each thing a detector finds, best first:
  class=dog score=0.86 x0=133 y0=207 x1=326 y1=543
x0 y0 x1 y1 are its box in the picture's pixels. Nothing found is said so.

Arguments:
  imagepath  the picture (JPEG, PNG, GIF, WebP, ...)
  -c         only these classes, comma-separated (person,car)
  -t         the lowest score kept, 0 to 1 (0.30 unless given)

Examples:
  vision /tmp/photo.jpg
  vision -c person,car /tmp/street.png

Notes:
  - The picture goes only to the vision service at /mnt/vision
    (visionfs(4)): this machine's, or another machine's mounted there.
    There is no cloud backend.
  - Requires /mnt/vision with a model loaded.
