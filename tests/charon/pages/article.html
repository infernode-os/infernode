Plan 9 from Bell Labs

Plan 9 from Bell Labs is a distributed operating system which originated from the Computing Science Research Center at Bell Labs in the mid-1980s and built on UNIX concepts first developed there in the late 1960s.

Design

Plan 9 replaced Unix as Bell Labs's primary platform for operating systems research. It explored several changes to the original Unix model that facilitate the use and programming of the system, notably in distributed multi-user environments. The system is built on the idea that everything is a file: /proc, /net, and the window system are all file servers.

The foundations of the system are built on two ideas: a per-process name space and a simple message-oriented file system protocol.
  • Per-process namespaces
  • The 9P protocol, carried over any reliable transport
  • UTF-8, invented for Plan 9 in 1992
