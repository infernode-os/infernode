# tools/pi-btfw-manifest-zero2w.txt -- the Raspberry Pi Zero 2 W's
# Bluetooth patches, pinned by commit and SHA256.  Read by
# tools/pi-firmware.sh, which tools/mkpiimage.sh runs for rpizero2w.
#
# Format: tools/pi-firmware-manifest.txt's.
#
# WHICH ONE
#
# One per radio (tools/pi-firmware-manifest-zero2w.txt): Raspberry Pi's
# packaging (debian/bluez-firmware.links) links
# BCM43430A1.raspberrypi,model-zero-2-w.hcd to SYN43430A1.hcd (the
# CYW43436s) and BCM43430B0.raspberrypi,model-zero-2-w.hcd to
# SYN43430B0.hcd (the CYW43436).  The controller names itself over HCI
# (Read Local Name: BCM43430A1 or BCM43430B0) before a patch is sent;
# the card's bt file names the one that board takes.
#
# LICENCE, AND WHAT IS NOT YET DECIDED
#
# debian/copyright: debian/firmware/synaptics/* under
# SYNAPTICS-END-USER-SOFTWARE-TOOL-LICENSE, whose text (LICENSE.synaptics
# beside them) is os/bcm/card/LICENCE.synaptics-bt.  Not the Wi-Fi
# firmware's terms: it allows copying and redistribution in object code
# "for use in connection with Synaptics integrated circuits" (2(c)), but
# limits use to configuration and testing of one's products (2(b)),
# excludes products whose failure could cause injury (4(h)), and may be
# ended by Synaptics on notice (10).  These files are on a card
# mkpiimage.sh makes; whether a release's Zero 2 W image carries them is
# not decided.
#
# REPINNING: as tools/pi-btfw-manifest.txt says.
