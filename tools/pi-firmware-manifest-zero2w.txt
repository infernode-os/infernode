# tools/pi-firmware-manifest-zero2w.txt -- the Raspberry Pi Zero 2 W's
# Wi-Fi firmware, pinned by commit and SHA256.  Read by tools/pi-firmware.sh,
# which tools/mkpiimage.sh runs for the rpizero2w board.
#
# Format: tools/pi-firmware-manifest.txt's.
#
# TWO RADIOS
#
# A Zero 2 W has a CYW43436 or a CYW43436s, by when it was made.  The
# driver reports which (ifstats, "chip:"): the 43436 is chip 43430
# (0xa9a6) rev 2, the 43436s 43430 rev 1 -- the same id as the 3B's and
# Zero W's CYW43438.  os/init/osinit.b's radiofirmware picks the files by
# it, and takes the 43436s's for rev 1 when the card has them, as this
# card does.  Raspberry Pi's packaging makes the same choice by board
# name (brcmfmac43430-sdio.raspberrypi,model-zero-2-w.bin is a link to
# brcmfmac43436s-sdio.bin; brcmfmac43430b0-...-zero-2-w.bin and
# brcmfmac43436-...-zero-2-w.bin to brcmfmac43436-sdio.bin).  The 43436s
# has no regulatory table.
#
# LICENCE
#
# Synaptics's, not Cypress's: debian/copyright at this commit puts
# debian/config/brcm80211/*/*43436* under "License: Synaptics", the
# SYNAPTICS WIRELESS CONNECTIVITY DEVICES DRIVER END USER LICENSE
# AGREEMENT (BINARY DISTRIBUTION), whose text is
# os/bcm/card/LICENCE.synaptics-wifi: distribution in object form,
# unmodified, "solely for use in connection with Synaptics integrated
# circuit products".  The same road as the CYW43455's files
# (tools/pi-firmware-manifest.txt): never in the tree or a hosted
# release; on a Zero 2 W's card beside its licence.
#
